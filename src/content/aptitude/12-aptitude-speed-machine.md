# Aptitude speed machine guide

Aptitude is not slow school math. In interviews and placement tests, it is fast
classification, clean arithmetic, and option elimination.

The target loop is:

1. Classify the topic.
2. Identify the unknown.
3. Pick the formula or shortcut.
4. Estimate the answer range.
5. Calculate.
6. Eliminate impossible options.
7. Move on if time is bleeding.

## Non-negotiable memory table

You should recall these without effort:

| Item | Must know |
|---|---|
| Tables | 1 to 20 |
| Squares | 1 to 30 |
| Cubes | 1 to 15 |
| Fractions | `1/2`, `1/3`, `1/4`, `1/5`, `1/6`, `1/8`, `1/10`, `1/12` |
| Percentages | 5%, 10%, 12.5%, 20%, 25%, 33.33%, 50%, 75% |

Fast aptitude starts before the question. It starts with arithmetic memory.

## Fraction-percentage anchors

| Fraction | Percent |
|---|---:|
| `1/2` | 50% |
| `1/3` | 33.33% |
| `1/4` | 25% |
| `1/5` | 20% |
| `1/6` | 16.67% |
| `1/8` | 12.5% |
| `1/10` | 10% |
| `1/12` | 8.33% |

If you see 12.5%, think `1/8`. If you see 33.33%, think `1/3`.

## Percentage machine

Formula:

```text
percentage change = change / original * 100
```

The denominator is the original value.

Example:

```text
Price rises from 400 to 500.
Change = 100.
Percent rise = 100 / 400 * 100 = 25%.
```

Reverse percentage:

```text
Final = Original * (1 + rate/100)
Original = Final / (1 + rate/100)
```

If a value becomes 120 after a 20% increase:

```text
Original = 120 / 1.2 = 100
```

## Ratio machine

Ratio means shares.

If `A:B = 3:5`, total parts = 8.

If total is 160:

```text
One part = 160 / 8 = 20
A = 3 * 20 = 60
B = 5 * 20 = 100
```

For changed ratios, convert both old and new ratios into parts and align the
unchanged quantity.

## Average machine

Formula:

```text
average = total / count
total = average * count
```

Most average questions become total questions.

Example:

```text
Average of 5 numbers is 18.
Total = 5 * 18 = 90.
If one more number 24 is added:
New total = 114.
New average = 114 / 6 = 19.
```

Weighted average:

```text
combined average = total value / total count
```

Do not average averages directly unless the counts are equal.

## Time, speed, distance

Core:

```text
speed = distance / time
distance = speed * time
time = distance / speed
```

Unit conversion:

```text
km/h to m/s: multiply by 5/18
m/s to km/h: multiply by 18/5
```

Relative speed:

```text
opposite direction = speed1 + speed2
same direction = speed difference
```

Train and platform problems often hide relative speed.

## Time and work

If A finishes work in 10 days:

```text
A's one-day work = 1/10
```

If B finishes in 15 days:

```text
Together per day = 1/10 + 1/15 = 1/6
Together time = 6 days
```

Use work rate. Do not try to reason with vague "faster/slower" language.

## Option elimination

Before doing full arithmetic, estimate.

Example:

```text
18% of 497
Approx 20% of 500 = 100.
So answer must be near 90, not 40 or 180.
```

This saves time and catches calculation mistakes.

## Timed-section rule

Use a strict timer:

- Easy arithmetic: 30-45 seconds.
- Medium calculation: 60-90 seconds.
- Long reasoning: 2 minutes maximum before marking and moving.

The goal is not solving one heroic question. The goal is maximizing total score.

## Error log

After every aptitude mistake, classify the error:

| Error type | Meaning |
|---|---|
| Formula | You did not know the rule. |
| Classification | You picked the wrong topic. |
| Arithmetic | You knew the method but calculated badly. |
| Unit | You mixed hours/minutes, km/m, or percent/base. |
| Time | You spent too long. |

Train the error type. Do not randomly redo the same chapter.

## Recall hook

Classify first. Convert to formula. Estimate. Calculate. Eliminate. Move.
