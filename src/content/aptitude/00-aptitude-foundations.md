# Aptitude foundations

Aptitude is speed plus accuracy. You do not need fancy math first. You need
basic arithmetic, ratios, percentages, unit conversion, and a habit of checking
whether the answer is reasonable.

## What to master first

- Tables from 1 to 20.
- Squares up to 30.
- Cubes up to 15.
- Fractions to percentages.
- Percentage increase and decrease.
- Ratio simplification.
- Average formula.
- Time, speed, and distance units.
- Work-rate formula.

## Core formulas

| Concept | Formula |
|---|---|
| Percentage | `part / whole * 100` |
| Percentage change | `change / original * 100` |
| Profit percent | `profit / cost price * 100` |
| Average | `sum / count` |
| Speed | `distance / time` |
| Work rate | `work / time` |
| Simple interest | `P * R * T / 100` |

## Speed habit

Before solving, classify the question:

1. Is it percentage, ratio, average, speed, work, probability, or logic?
2. What is the unknown?
3. Can options be eliminated?
4. Is approximation enough?
5. Does the final answer make sense?

## Example

If a value increases from 80 to 100:

```text
change = 20
percentage increase = 20 / 80 * 100 = 25%
```

The denominator is the original value, not the final value.

## Common traps

- Using the final value instead of original value for percentage change.
- Mixing hours and minutes.
- Adding percentages directly when bases are different.
- Forgetting that average depends on both total and count.
- Spending too long on one question in a timed section.

## Recall hook

Classify first, calculate second, verify third.
