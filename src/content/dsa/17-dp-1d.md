# Dynamic Programming — 1D

DP is *recursion + memoization* — solve a problem by reusing answers to overlapping subproblems. If `@cache` makes a naive recursion fast, you have a DP solution.

## The thinking pattern

Every DP starts with the **same five steps**:

1. **State.** What variable(s) define a subproblem? For 1D DP, usually a single index `i`.
2. **Definition.** What does `dp[i]` mean in plain English? Write it as a contract.
3. **Recurrence.** How does `dp[i]` relate to smaller `dp[j]`?
4. **Base case.** What's `dp[0]`? `dp[1]`?
5. **Answer.** Is it `dp[n]`? `dp[n-1]`? `max(dp)`?

## Climbing stairs — the warm-up

You can climb 1 or 2 steps at a time. How many ways to reach step `n`?

```python
def climb(n):
    if n <= 2: return n
    dp = [0] * (n + 1)
    dp[1], dp[2] = 1, 2
    for i in range(3, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

- State: `i` = current step.
- Definition: `dp[i]` = number of ways to reach step `i`.
- Recurrence: `dp[i] = dp[i-1] + dp[i-2]` — last step was either size 1 or 2.

You can drop the array to two variables (`O(1)` space) since you only need the last two values.

## House robber

You rob a row of houses. Can't rob two adjacent ones. Maximize loot.

```python
def rob(nums):
    prev1, prev2 = 0, 0            # max if we end at i-1 / i-2
    for x in nums:
        prev1, prev2 = max(prev1, prev2 + x), prev1
    return prev1
```

- Definition: `dp[i]` = max loot from `nums[:i+1]`.
- Recurrence: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` — skip this house, or rob it (and skip the previous).

## Coin change — min coins to make amount

```python
def coin_change(coins, amount):
    INF = float("inf")
    dp = [INF] * (amount + 1)
    dp[0] = 0
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    return dp[amount] if dp[amount] != INF else -1
```

- Definition: `dp[a]` = min coins for amount `a`.
- Recurrence: `dp[a] = min(dp[a - c] + 1 for c in coins if c <= a)`.
- Base: `dp[0] = 0`.

`O(amount × len(coins))` time.

## Longest Increasing Subsequence

```python
def lis(nums):
    if not nums: return 0
    dp = [1] * len(nums)
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

`O(n²)`. An `O(n log n)` solution exists using binary search + patience sorting — know it exists, code it if asked.

- Definition: `dp[i]` = length of LIS ending at index `i`.
- Recurrence: extend the best `dp[j]` where `j < i` and `nums[j] < nums[i]`.

## Top-down (memoized recursion) vs bottom-up (tabulation)

Both work. Pick whichever you can write cleanly under pressure.

```python
# top-down — write the recurrence as you derived it
from functools import cache

def rob(nums):
    @cache
    def best(i):
        if i < 0: return 0
        return max(best(i - 1), best(i - 2) + nums[i])
    return best(len(nums) - 1)
```

```python
# bottom-up — explicit table
def rob(nums):
    n = len(nums)
    if n == 0: return 0
    dp = [0] * n
    dp[0] = nums[0]
    if n > 1: dp[1] = max(nums[0], nums[1])
    for i in range(2, n):
        dp[i] = max(dp[i-1], dp[i-2] + nums[i])
    return dp[-1]
```

**Heuristic:** start top-down if you wrote a recursion first. Convert to bottom-up if you need to optimize space or iteration order.

## Space optimization

If `dp[i]` only depends on `dp[i-1]` and `dp[i-2]`, you only need two variables. Most 1D DPs collapse from `O(n)` to `O(1)` space this way.

## Recognizing a DP problem

- "How many ways to ...", "minimum cost to ...", "longest / shortest ...", "maximum profit ..."
- The naive recursion has **overlapping subproblems** (same call args repeated).
- The problem has **optimal substructure** — the answer for `n` depends on answers for smaller inputs.

## Common bugs

- **Wrong base case.** Trace your recurrence at `n = 0` and `n = 1` manually.
- **Off-by-one on array sizing.** `dp = [0] * (n + 1)` vs `[0] * n` — pick a convention and check both ends.
- **Mutating shared state across `@cache`d calls.** The cache assumes the function is pure. If args contain mutable objects, cache hits return stale answers.
- **Forgetting to convert top-down to iterative** when Python's recursion limit bites.
